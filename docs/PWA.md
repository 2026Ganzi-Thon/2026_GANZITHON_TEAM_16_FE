# PWA 설치와 Android 패키징

## 이번 변경

- manifest.webmanifest: 모우 앱 이름·아이콘·범위·시작 URL·standalone 표시 모드.
- 기존 모우 favicon 이미지로 만든 192/512 아이콘, 마스커블 안전 여백을 둔 512 아이콘, Apple touch 180 아이콘.
- 프로덕션에서만 루트 서비스 워커 등록. 로컬 개발 서버는 등록하지 않으며 기존 웹 로그인 흐름은 유지합니다.
- 오프라인에서는 연결 안내를 제공합니다. 대화·일기 작성과 조회는 온라인 연결이 필요합니다.
- 오프라인 안내와 앱 아이콘만 캐시합니다. 사용자 페이지 HTML·API·소셜 콜백·첨부 사진·서명 URL은 캐시하지 않습니다.
- 새 서비스 워커는 사용 중인 화면을 강제로 교체하지 않습니다. 이전 앱 창을 닫고 다시 열면 대기 중인 새 버전이 활성화됩니다.
- Cloudflare `_headers`에서 sw.js·매니페스트 재검증을 설정하며, `/api/*` 전용 Functions 라우팅을 유지합니다.

## 확인

`npm run build` 후 `npm run check:pwa`. 실제 프로덕션 빌드를 로컬 preview로 띄워 브라우저에서 매니페스트·아이콘·서비스 워커·오프라인 안내·API 캐시 제외·연결 복구를 검증합니다. 휴대폰 설치 안내 노출과 APK 동작은 배포 후 실제 기기에서 별도 확인합니다.

공식 저장소에서 PR 병합·Cloudflare 재배포 후 Android Chrome의 앱 설치/홈 화면에 추가 기능으로 확인합니다. 브라우저별 설치 지원 방식과 안내 조건은 다를 수 있습니다.

## PWABuilder 후속 작업

1. https://www.pwabuilder.com/ 에 확정된 Cloudflare 배포 URL을 넣고 검사합니다.
2. Android 패키징에서 앱 이름·고정 패키지 ID·서명 키를 정하고 패키지를 내려받습니다.
3. 받은 assetlinks.json을 공식 저장소의 `public/.well-known/assetlinks.json`에 추가하고 재배포합니다. 서명 인증서 지문과 패키지 ID는 실제 APK와 일치해야 합니다.
4. APK 설치 후 로그인·사진 업로드·뒤로 가기·앱 재실행을 확인합니다. AAB는 스토어 제출용입니다.

이번 변경은 PWA 준비이며 APK 생성 완료가 아닙니다. 임의의 인증서 지문이나 임시 assetlinks.json은 넣지 않았습니다. 서명 키/비밀번호는 공개 저장소에 올리지 않고 안전하게 별도 보관합니다. 앱 배포·제출 방식은 대회 운영 규정을 확인하고 관련 변경·패키징을 마감 전에 완료합니다.
