# 인수인계 — 채팅·보관함 로컬 구현 (2026-11-12)

브랜치 `feature/chat-ui` (기준 `develop` `dbc1de4`). API 계약·오류 코드·남은 우선순위는 11-10 인수인계 문서를 따릅니다. 이 문서는 그 이후 바뀐 점만 적습니다.

## 실행

`npm ci` → `npm run dev` → `http://127.0.0.1:3000`
`.env.local`에 카카오 키가 없으면 로그인 버튼 아무거나 누르면 미리보기로 메인에 들어갑니다.

## 바뀐 점

- **대화 `/chat`**: 전송·임시 답변·새로고침 복원, 5왕복 기준 진행도 모달과 생성 버튼, 최근 메시지 수정, 종료 대화 입력 차단. `/chat/ready`, `/chat/progress`는 `/chat`으로 통합
- **보관함 `/archive`**: 실제 대화 목록(월별·최신순·20개씩), 누르면 `/chat?session=<id>`. 처음엔 샘플 대화 2개
- **일기 생성**: 5왕복 후 대화 종료 → 사용자 메시지를 모은 로컬 초안으로 작성 화면 이동
- **캐릭터**: 카드별 상세 모달 `/characters/detail?character=kind|cool|cheerful|queen|confident` (설명은 임시 초안)
- **캘린더**: 기록 있는 날(1·5·6일) → `/diary/detail?date=YYYY-MM-DD`, 없는 날은 안내
- **기타**: 낮은 창에서 화면 전체 보이게 축소, 기록 미리보기 말줄임, 선택 삭제 예시 2개로 축소

## 데이터

| 화면 | 현재 | 연동 시 |
| --- | --- | --- |
| 대화·보관함 | localStorage 가짜 API (백엔드 DTO와 같은 형식) | `src/features/chat/api.ts`만 HTTP 구현으로 교체 |
| 캐릭터 | `src/features/characters/catalog.ts` | 캐릭터 API로 교체 |
| 일기·캘린더·삭제·통계 숫자 | Figma 예시 | 화면별로 예시 노드를 숨기고 실제 목록 연결 |

채팅 연동 시 주의: 임시 캐릭터 ID `local-mowoo-kind`를 보유 캐릭터 UUID로 바꾸고, 응답의 `isSuccess`·`code`·`message`는 HTTP 모듈에서 처리합니다.
